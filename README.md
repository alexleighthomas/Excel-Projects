📊 Excel Data Analysis Project — Data Technician Bootcamp
This repository contains my completed Excel-based data analysis work from Week 1 of the Data Technician Bootcamp. The project demonstrates practical skills in cleaning, analysing, transforming, and visualising retail and sales datasets using core Excel functions and tools.

🧰 Skills Demonstrated
✔️ Excel Formulas
Throughout the project, I applied a wide range of essential Excel formulas used in real-world data roles:

- SUM — calculating totals
- SUMIF / SUMIFS — conditional totals
- AVERAGE / AVERAGEIF — mean values with or without criteria
- DATE, MONTH, YEAR — extracting and manipulating date values
- UNIQUE — identifying distinct values in a dataset
- VLOOKUP — performing lookups across tables
- IF / Nested IF — value flagging and categorisation
- SWITCH — classifying sales volumes into High, Medium, and Low categories

**Example used in the project:
=SWITCH(TRUE, C2 > 600, "High", C2 >= 300, "Medium", "Low")**

🔎 Data Cleaning & Preparation
Converted raw datasets into structured Excel Tables using Ctrl + T

Removed hidden spaces and ensured correct data types

Applied sorting (largest → smallest, alphabetical, custom)

Used filters to isolate specific age groups, product categories, and sales ranges
