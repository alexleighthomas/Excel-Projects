✔️ Excel Formulas
Throughout the project, I applied a wide range of essential Excel formulas used in real-world data roles:

- SUM — calculating totals
- SUMIF / SUMIFS — conditional totals
- AVERAGE / AVERAGEIF — mean values with or without criteria
- DATE, MONTH, YEAR — extracting and manipulating date values
- UNIQUE — identifying distinct values in a dataset
- VLOOKUP — performing lookups across tables
- IF / Nested IF — value flagging and categorisation
- SWITCH — classifying sales volumes into High, Medium, and Low categories
