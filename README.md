<h1> 📊 Excel Data Analysis Project — Data Technician Bootcamp </h1>

<p1> This repository contains my completed Excel-based data analysis work from Week 1 of the Data Technician Bootcamp. The project demonstrates practical skills in cleaning, analysing, transforming, and visualising retail and sales datasets using core Excel functions and tools. </p1>

<h2> 🧰 Skills Demonstrated </h2>
<h3> ✔️ Excel Formulas </h3>
<p1> Throughout the project, I applied a wide range of essential Excel formulas used in real-world data roles:

- SUM — calculating totals

- SUMIF / SUMIFS — conditional totals

- AVERAGE / AVERAGEIF — mean values with or without criteria

- DATE, MONTH, YEAR — extracting and manipulating date values

- UNIQUE — identifying distinct values in a dataset

- VLOOKUP — performing lookups across tables

- IF / Nested IF — value flagging and categorisation

- SWITCH — classifying sales volumes into High, Medium, and Low categories </p1>


<h2> 🔎 Data Cleaning & Preparation </h2>
<p1> 

- Converted raw datasets into structured Excel Tables using Ctrl + T

- Removed hidden spaces and ensured correct data types

- Applied sorting (largest → smallest, alphabetical, custom)

- Used filters to isolate specific age groups, product categories, and sales ranges </p1>

<h2> 📈 PivotTables & PivotCharts </h2>
<p1> I created multiple PivotTables to summarise:

- Retail sales by age, product, and commission

- Student performance across subjects

- Bike sales by country, age group, and gender

- Device sales by county and product </p1>

<p1> Key PivotTable skills demonstrated:

- Adding rows, columns, values, and filters

- Masking empty cells

- Sorting values within PivotTables

- Creating PivotCharts for visual insights (bar charts, column charts, pie charts) </p1>

<h2> 🎨 Data Visualisation </h2>
<p1> To make insights clear and presentation-ready, I used:

- Conditional formatting (colour scales, value highlighting)

- PivotCharts for summarising trends

- Custom formatting for currency, percentages, and categories </p1>

<p1> These visualisations were used to explain:

- Customer churn patterns

- Product performance by region

- Sales trends across demographics </p1>
